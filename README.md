# Financial Statement Audit Reviewer

AI-powered pre-review assistant for financial statements.

## Download

The installable plugin package will be published here as **plugin.zip**.

> Package upload is pending. Until `plugin.zip` appears in this repository, the download link is not active.

## Commands

- `/audit` — prepare an English pre-review report.
- `/auditbd` — prepare a Bangla-English pre-review report.

## Scope

The reviewer can help identify calculation issues, inconsistencies between financial statements, schedule and note mismatches, balance roll-forward issues, disclosure gaps, and presentation concerns.

## Important notice

This tool supports a preliminary review only. It does not provide an independent audit opinion, assurance, or certification, and it does not replace the professional judgment and procedures of a qualified auditor.
